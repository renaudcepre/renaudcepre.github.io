# Yorkshire Technologies Incorporated

> Retro showcase site, a 2004 web mockup and proud of it. Zero
> framework, zero rendering dependency.

![Status](https://img.shields.io/badge/status-Live-blue) [![Site](https://img.shields.io/badge/site-yti--website.pages.dev-blue)](https://yti-website.pages.dev)

## The thing

A two-person project, with a friend. A fake tech company whose
manifesto fits in one line: we build tech projects for research, fun,
optimization, and above all for the legend and glory of the Yorkshire
Terrier. The rest of the manifesto: "Time does not matter. We
procrastinate."

The site is a playground. An ASCII torus spinning on the home page, a
carousel of projects of which only one exists, a zine, a sequencer,
and SAM, the 1982 speech synthesizer, reading the site out loud and
singing.

Under the hood: Vite, strict TypeScript, native Web Components in
light DOM. All the visuals are hand-written procedural canvas, clean
WebGL is precisely the trap. The big ASCII data is generated by
scripts with assertions, never retyped. GitLab CI build, deployed on
Cloudflare Pages.

## Thalweg inside

The only horse on the carousel that actually exists:
[thalweg](/dev/lab/thalweg.md), the Rust engine compiled to
WebAssembly, runs further down the page. Each visitor's world sleeps
in their IndexedDB.

## Status

Live, main project of summer 2026. Unlimited procrastination, fully
